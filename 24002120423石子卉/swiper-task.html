作业任务一 · 提示词工程师让 AI 听懂需求 —— 两轮迭代记录与实测验证

本任务不写代码，写提示词：把需求"翻译"给 AI，让它生成 new Swiper('#wySw4', {...}) 配置（① 无缝循环 ② 3.2 秒自动翻页且手动操作后不停止 ③ 圆点分页器可点击 ④ 初始效果 cube），迭代至少 2 轮、保留每轮问答，并粘入页面实测验证。

第 1 轮 · 提示词（初稿）

用 Swiper 给 #wySw4 写一个初始化配置，要有循环和自动播放，3.2 秒翻一次，底部要有小圆点分页器，初始效果用 cube，切换动画时长 800 毫秒。

第 1 轮 · AI 回答

new Swiper('#wySw4', {
  loop: true,
  speed: 800,
  effect: 'cube',
  autoplay: { delay: 3200 },
  pagination: { el: '#wyPag4' }
});

一句话结论：第 1 轮配置不达标——自动播放在手动操作后会永久停止，圆点无法点击跳转。

第 2 轮 · 提示词（逐条纠偏）

上一轮有两处不达标，请按 Swiper 11 官方参数重写 #wySw4 配置，必须同时满足：① loop: true 无缝循环，翻到最后一张能继续翻回第一张；② autoplay 的 delay 为 3200 且 disableOnInteraction: false，手动操作后自动播放不停止；③ 分页器用 #wyPag4，圆点可点击跳转；④ 初始 effect: 'cube'，动画时长 speed: 800。只给配置代码。

第 2 轮 · AI 回答（最终采纳）

new Swiper('#wySw4', {
  loop: true,                    // ① 无缝循环
  speed: 800,                    // 切换动画时长
  effect: 'cube',                // ④ 初始 3D 立方体
  autoplay: {
    delay: 3200,                 // ② 每 3.2 秒自动翻页
    disableOnInteraction: false  // ② 手动操作后不停止
  },
  pagination: {
    el: '#wyPag4',               // ③ 圆点分页器
    clickable: true              // ③ 圆点可点击跳转
  }
});

一句话结论：第 2 轮配置粘入页面实测，四项需求全部实现，翻到最后一张还能无缝绕回第一张。

③ 关键对话记录 · keyboard 键盘控制

第 1 轮提示词：给 #wySw4 这个 Swiper 加上 keyboard 键盘控制，按左右方向键能翻页，保留原有的循环、自动播放、圆点分页配置。

AI 回答（要点）：在配置里加 keyboard: true 即可，并给出代码。

let wySw4 = new Swiper('#wySw4', {
  loop: true,
  speed: 800,
  effect: 'cube',
  pagination: { el: '#wyPag4', clickable: true },
  autoplay: { delay: 3200, disableOnInteraction: false },
  keyboard: true        // 新增：键盘控制
});

重要往返 · 我发现的问题：页面上"效果实验台"的七个按钮是销毁旧实例再重建的，AI 第一次给的代码只改了初始配置——一旦切到别的效果再切回来，重建的实例没有 keyboard，键盘控制就失效了。我的修改：把 keyboard: true 同时写进按钮的重建配置，保证任何效果下键盘都能用。

// 按钮点击重建实例时也要带上 keyboard（AI 第一次漏掉的部分）
wySw4 = new Swiper('#wySw4', {
  loop: true,
  speed: 800,
  effect: btn.dataset.fx,
  pagination: { el: '#wyPag4', clickable: true },
  autoplay: { delay: 3200, disableOnInteraction: false },
  keyboard: true        // 补上：否则切完效果键盘失效
});
