移动一帖，以 SVG 成其形。iconfont 之 symbol 注于页面，由 use 取用；其形多色自随，不因墨改。线性之 user 取自 Lucide，随墨而变。

纸飞机 use #icon-zhifeiji viewBox 1024
西瓜 use #icon-xigua viewBox 1024
比萨 use #icon-pisa viewBox 1024 
<!-- SVG symbol：脚本注入，use 取用 -->
<script src="cdn/iconfont/iconfont.js"></script>
<svg class="szh_svg_icon">
  <use xlink:href="#icon-zhifeiji"></use>
</svg>
<!-- 第四栏线性图标 -->
<i data-lucide="user"></i>

iconfont.js 于页面载入时将三枚 symbol 注入文档，SVG 以 use 引之，放大不糊，多色自随。字体法门另见 字为形手帖。
