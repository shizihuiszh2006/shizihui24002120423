字体如何成形

一枚字体图标，自字体文件到页上之形，经三步而成。

其一 载体
图形铸入字体文件 fa-solid-900.woff2，由 CSS 的 @font-face 一并载入。本页字体即取自本地 cdn/fontawesome/webfonts 目录，不假外网。
其二 映射
每枚图标占用 Unicode 私用区的一个码位，如居所 house 占 f015，星芒 star 占 f005。字体在，码位便有了模样。
其三 呈现
写下 <i class="fa-solid fa-house"></i>，伪元素 ::before 以 content 取出码位，图形随字号与颜色而变。它首先是字，然后才是形。
<!-- 写下一枚图标 -->
<i class="fa-solid fa-pen-nib"></i>

/* 其背后大意如此（摘自 all.min.css） */
@font-face {
  font-family: "Font Awesome 6 Free";
  font-weight: 900;
  src: url("../webfonts/fa-solid-900.woff2") format("woff2");
}
.fa-solid::before { content: var(--fa); }
